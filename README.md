# Water Quest — charity: water Game Prototype

A responsive HTML/CSS/JavaScript prototype inspired by charity: water's clean-water mission.

## Rubric features
- Core interactivity: clickable clean-water targets update score.
- Score tracking and display.
- 30-second timer.
- Responsive desktop/mobile layout.
- charity: water-inspired yellow/water visual design.
- LevelUp challenge: polluted water deducts 10 points.
- LevelUp reset: Reset game button restarts the round.
- LevelUp celebration: reaching 100 points triggers confetti.

## Play
Open `index.html` in a modern browser, or use the GitHub Pages URL once Pages is enabled for this repository.

## Submission
The course worksheet asks for the live GitHub Pages URL, not the repository URL. Test the published link in an incognito/private browser before submitting.
