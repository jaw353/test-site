## 2. Reflection: Prototyping

I kept the first version focused on a small set of mechanics that I could test: a 30-second timer, clickable targets, score tracking, a goal, and a reset option. I chose a simple clean-water collection game instead of trying to build a large game with multiple levels. Once the core idea was working, I added a polluted-water penalty and a celebration for reaching the goal. One thing that stood out to me was how much JavaScript can change a page from a static design into an experience that responds immediately to a player's choices. I also learned that responsive design and clear feedback matter because players need to understand the rules quickly on both a phone and a computer. In the future, I would sketch and test the main game states earlier, then add visual polish after checking each mechanic individually.
